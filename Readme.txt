# YOLO-Based Traffic Violation Detection System

## Overview
An academic project exploring automated traffic monitoring using YOLO object detection and a Flask web application.

## Features
- Image upload and object detection
- Video upload and frame-by-frame detection
- Live camera object detection
- Display of annotated images and processed videos
- Web interface built with Flask

## Technologies
- Python
- YOLO / Ultralytics
- OpenCV
- Flask
- SQLite
- FFmpeg

## Installation
1. Install a compatible version of Python.
2. Install the required Python packages using `pip install -r requirements.txt`.
3. Install FFmpeg separately and ensure it is accessible from your system PATH.
4. Place the required model weights in the documented model directory.
5. Run the application using the appropriate Python entry point.

## Note
Traffic violation detection and automatic number-plate recognition are distinct tasks. Document the number-plate recognition and character-reading functionality here only if it is implemented in the project.
